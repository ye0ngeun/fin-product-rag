## 4. MMR 검색 비교 (F2014)

설정: 문턱(관련도 0.3, 상대 0.15)을 통과한 후보 최대 20개 중 λ=0.7로 Top-k 5개.

- 유사도 검색은 같은 위키 문서의 여러 청크가 근거에 몰리는 경우가 있고, MMR은 이를 줄이고 출처 종류를 넓힙니다.
- 질문별 근거 수, 서로 다른 문서 수, 같은 문서 중복, 출처 종류 수는 `검증결과/search_compare.md` 에 있습니다.
- 필수 구현(유사도)과 비교: 기본값은 유사도로 두고, 길잡이 화면에서 질문마다 MMR을 고를 수 있습니다.

## 5. RAG 사용 전후 품질 비교 (F2015, 4.6)

같은 모델(`gpt-4.1-mini`, temperature 0)에 질문만 준 답(RAG 없이)과 근거를 붙인 답(RAG)을 나란히 비교했습니다. 질문 원문과 두 답 전문은 `검증결과/rag_compare.md` 에 있습니다.

| 기준 | RAG 없이 | RAG |
| :--- | :--- | :--- |
| 자동 점검 정답 | 3/6 | **5/6** |
| 사실 정확성 (q1~q3 공시값, q4·q5 핵심 낱말) | (질문별 판정은 `rag_compare.md`) | 공시 텍스트의 값을 그대로 인용 |
| 근거 제시 (인용 출처 수) | 출처 없음 | 문장마다 `[근거 n]`, 원문 위치 표시 |
| 모름 인정 (q6 금리 전망) | (`rag_compare.md`) | "확인되지 않습니다" |

- **q5 원리금균등상환 (한계 사례):** 색인한 위키·용어사전에 해당 항목이 없어 근거 0개. RAG 답은 지어내지 않고 "확인되지 않습니다"로 답해 자동 점검은 틀림이지만, 근거 없는 내용을 만들지 않은 것은 의도한 동작입니다. 해당 용어 문서를 추가 색인하면 개선됩니다.
- 질문 선정: 특정 상품 공시값 3개, 용어 2개, 문서로 알 수 없는 질문 1개 (`config/eval_questions.yaml`).
