SSAFY AI 코어 프로젝트 2회차 (RAG 기반 도메인 지식 서비스)

> 본 서비스는 정보 제공용이며 금융 전문가의 조언을 대신하지 않습니다.
> 상품 정보는 금융상품통합비교공시시스템(금융감독원) 금융회사 상품정보를 사용한 결과이며, 금융감독원은 정보의 정확성·최신성을 보증하지 않습니다.

## 1. 서비스 개요

《불빛 하나》는 서울 야경 위에서 내집마련 대출을 시뮬레이션하는 서비스입니다. 사용자는 현금·소득·생활비를 정하고 대출금과 기간을 조정하며, 그 결과로 살 수 있는 집(실거래 사례)의 불빛과 매달 남는 돈을 봅니다. 상품을 고르면 RAG 길잡이가 금감원 공시 정보와 용어사전·위키백과를 근거로 상품 조건과 용어를 설명하고, 답변마다 근거 출처를 보여 줍니다.

## 2. 도메인 확정과 조건 충족 근거 (2.1)

도메인: **개인 대출상품** (주택담보대출·전세자금대출·개인신용대출)

| 조건 | 충족 근거 |
| :--- | :--- |
| 항목 메타데이터 약 100건 이상 | 금감원 금융상품한눈에 Open API 대출 3종, 은행·여신전문·저축은행·보험 권역. 2026-10-21 수집 284건(주택담보 112·전세자금 58·개인신용 114), 색인 시점 `loan_meta` 285건 |
| 항목별 외부 문서 | 한국어 위키백과(질문 때 수집), 한국주택금융공사 단어사전(CSV 2,829건), 한국은행 경제금융용어 800선(PDF), 우체국예금보험 금융용어사전(CSV 1,198건), 우체국 챗봇 금융용어 사전(CSV 1,038건). `loan_docs` 약 4,900청크 |
| 근거가 필요한 질문 3개 이상 | 아래 2-1 |
| 위험 도메인 여부·면책 | 금융 판단이 걸린 위험 도메인. 화면 하단과 길잡이 답변 아래에 면책 문구와 금감원 출처 문구(이용약관 제9조 4항)를 항상 표시 |

### 2-1. 근거 없이 답하면 틀리거나 위험한 질문

| 질문 | 근거 없이 답할 때의 위험 |
| :--- | :--- |
| 우리은행 우리아파트론의 중도상환수수료는 어떻게 돼? | 상품마다 다른 공시값. 모델이 일반적인 수치를 지어내면 실제 비용 판단을 그르침 |
| 우리은행 우리아파트론의 최저 금리는 몇 %야? | 공시 기간마다 바뀌는 숫자. 학습 데이터의 낡은 값이나 추측값이 나옴 |
| 우리은행 우리전세론(주택금융보증)의 연체 이자율은? | 상품 공시에만 있는 조건 |
| LTV가 뭐야? | 제도 용어. 근거 없이 답하면 규제 비율 같은 시점 의존 숫자를 단정할 수 있음 |
| 우리아파트론 금리는 다음 달에 오를까? | 문서로 알 수 없는 예측. 근거가 없으면 "확인되지 않습니다"로 답해야 함 |
